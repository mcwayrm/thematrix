# The Matrix

The Matrix is an application to determine the relationship between firm activity and the environment. 
To achieve this we need to know where firms are located, what they do in those locations, and how much do they at those locations. 
The Matrix is designed to capture these three pieces of information: 

**Where, What, and How Much?**
